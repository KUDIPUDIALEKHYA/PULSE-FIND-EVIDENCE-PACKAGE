# Hardware
- ESP32
- GY-MCU8833 thermal module
- KY-038 acoustic sensor
- RA-02/SX1278 LoRa
- LEDs
- Buzzer
- Breadboard
- Jumper wires
- USB power

## Pins
Thermal: VCC 3.3V, GND, TXD GPIO16, RXD unused
Acoustic: VCC 3.3V, GND, AO GPIO34
Green LED GPIO25; Red LED GPIO27; Buzzer GPIO26
LoRa: NSS GPIO5, SCK GPIO18, MOSI GPIO23, MISO GPIO19, RST GPIO14, DIO0 GPIO2
